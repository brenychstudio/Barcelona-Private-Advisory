# Barcelona Private Advisory

Barcelona-first premium real-estate advisory demo built as a product-led property search experience with curated filtering, shortlist sharing, and bilingual EN/ES structure.

## Overview
Barcelona Private Advisory is a premium real-estate demo designed as a product, not just a website.
It combines advisory framing, curated search, property storytelling, and shareable shortlist behavior into one cohesive front-end system.

## Stack
- Astro
- React islands
- TypeScript
- Tailwind CSS
- Query state + local shortlist logic

- ## What it demonstrates
- Product demo thinking in real estate
- Premium advisory UX
- Search / ranking / shortlist logic
- Bilingual EN/ES front-end architecture
