# Barcelona Private Advisory

Premium Barcelona property advisory interface built as a portfolio-grade front-end product system. The demo turns buyer intent, district intelligence, property signals and shortlist context into a calm private acquisition workflow.

## Overview

Barcelona Private Advisory is a bilingual EN/ES real-estate advisory prototype for high-consideration property search. It is designed as a decision interface rather than a listing catalog: buyers move from private brief to Barcelona Lens, ranked recommendations, property acquisition files, inspection gallery, dossier and copy-ready inquiry handoff.

The project is a portfolio prototype, not a live brokerage or operating agency. Listings, contact details and advisory signals are demonstrative and ready to be replaced by verified production data.

## Product Features

- Buyer intent surface with advisory framing.
- Barcelona Lens for district logic, lifestyle fit and acquisition signals.
- Advisory-ranked search with field and index modes.
- Property acquisition files with risk notes, readiness, gallery and viewing-path action.
- Cinematic inspection gallery and property chamber flow.
- Private shortlist dossier using local browser state.
- Copy-ready inquiry handoff with no backend submission.
- Bilingual EN/ES routes, content and hreflang metadata.
- SEO, Open Graph, Twitter card, favicon, app icon and web manifest foundation.
- Portfolio capture-ready desktop, mobile and Spanish proof surfaces.

## Stack

- Astro
- React islands
- TypeScript
- Tailwind CSS
- Local state and URL-safe shortlist sharing
- Static build with sitemap and robots support
